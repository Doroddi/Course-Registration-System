# 변경 단위와 검증 계획

이 문서는 요구사항을 PR과 검증 결과에 연결하기 위한 계획이다. 완료 여부는 각 PR의 실제 변경 및 실행 결과로 판단하며, 아래 순서는 새 정책의 확정을 의미하지 않는다.

신청·취소·시간표 구현이 커지면 PR을 나누되, 공통 잠금 규칙을 함께 검토한다. 동시성 테스트는 마지막 단계까지 미루지 않고 해당 기능 PR부터 포함한다.

## 설계 PR과 환경 PR의 경계

- 설계 PR은 [본문 초안](reviews/api-design-pr.md)에 나열한 문서를 포함한다.
- README는 설계 문서 링크 변경과 실행 안내 변경을 나누어 반영한다.
- 기술 스택 문서의 선택 근거는 설계 PR에, 실제 빌드·실행 결과와 BOOTSTRAP 링크는 환경 PR에 포함한다. 선행 PR에서 아직 없는 파일을 참조하지 않도록 확인한다.
- 환경 PR에는 build.gradle.kts, Gradle Wrapper와 실행 스크립트, src의 기존 진입점 교체·새 서버·설정·테스트, compose.yaml, .env.example, .gitignore, BOOTSTRAP.md를 포함한다.
- AGENTS.md의 협업 범위 변경도 설계·기록 규칙 변경으로 별도 확인한다. 비밀 값이 들어간 .env 및 로컬 도구·빌드 산출물은 게시하지 않는다.
- 초기 설계가 미병합이면 후속 설계 PR은 initial-design을 기준으로 비교하고 의존 PR을 명시한다. 선행 PR 병합 후 기준 브랜치와 diff를 다시 확인한다. 초기 설계 PR에 후속 구현을 추가하지 않는다.

## 누락 방지 기준

- [요구사항](REQUIREMENTS.md)의 F01~F07, I01~I05, D01~D84, T01~T116를 기준으로 후속 PR에 관련 ID와 실제 테스트를 연결한다. 테스트 계획만 있는 항목을 통과로 표시하지 않는다.
- 인증은 추가 기능이지만 강좌·학생·교수 조회와 신청·취소·시간표의 선행 조건이므로 기능 완료 기준에 포함한다.
- 초기 데이터 규모·생성 제한 시간·건강 상태 응답을 API 구현과 함께 검증한다. 컨테이너 healthy와 서비스 준비 완료를 구분한다.
- 요구사항의 미정 목록은 관련 구현 전에 검토한다. 특히 대상 학기 설정 오류, 데이터 재생성, 계정·JWT 키·재발급, 물리 타입·인덱스, 잠금 대기 설정을 누락하지 않는다.
- 자동 재시도, 신청 기간·학년별 제한, 교수 시간 충돌 등 후속 검토 항목을 임의로 구현 범위에 넣거나 완료 처리하지 않는다.
- 각 PR은 변경 이유, 관련 정책, 실제 검증 결과, 남은 한계, 프롬프트 기록, AI 리뷰 및 사람 리뷰의 반영 결과를 구분한다.
- 핵심 기능은 작성자가 직접 구현하고 AI는 개념·완료 기준 안내와 리뷰를 지원한다. 기존 AI 작성 기반 코드도 실제 지원 범위를 기록하며 작성 주체를 바꾸어 표현하지 않는다.

## 초기 데이터·준비 상태의 검증 기록 계획

초기 데이터 PR에서는 아래 측정 조건과 결과를 함께 남긴다. 현재 구현과 실행 결과는 INITIAL_DATA.md와 INITIAL_DATA_PERFORMANCE.md를 기준으로 확인한다. 아래 항목 중 미구현 업무 API의 준비 확인은 최종 검증까지 남아 있다.

- 실행한 커밋, JDK·DB 버전, 실행 명령, 측정 환경과 DB 초기 상태를 명시한다.
- 학과 10개·강좌 500개·학생 10,000명·교수 100명 이상의 실제 생성 개수를 조회해 확인한다. 강좌별 수업 시간·담당 교수와 참조 관계의 완전성도 검사한다.
- 서버 프로세스 시작부터 초기 데이터 및 API 준비가 끝나 /health가 200을 반환하기까지의 시간을 측정한다. 데이터 생성 구간의 소요 시간과 구분하고, 1분 이내 조건 충족 여부를 기록한다.
- 준비 전후의 /health 응답과 준비 완료 후 사용 가능한 API 호출 결과를 기록한다. API가 아직 구현되지 않은 단계에서는 전체 준비 조건을 충족했다고 표시하지 않는다.
- 빈 DB 최초 실행과 데이터가 남아 있는 DB 재시작을 구분하여 중복 생성·실패 여부를 확인한다. 실행 횟수와 측정값을 함께 남기고 단일 실행 결과를 일반적인 성능으로 표현하지 않는다.
