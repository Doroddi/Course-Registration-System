# 초기 설계 AI 리뷰 및 반영 결과

대상: [PR #1](https://github.com/Doroddi/Course-Registration-System/pull/1)

검토 기준 커밋: `405f93a7f3334e785c0b940bcbbe77a8b853b57a`

문서 작성에 참여한 AI가 수행한 자체 리뷰이다. 사람 리뷰어의 승인이나 독립 AI 리뷰를 대신하지 않는다.

## 검토 결과와 조치

| 항목 | 발견 사항 | 반영 내용 |
|---|---|---|
| Gradle Wrapper 실행 권한 | `gradlew`가 Git에 `100644`로 저장돼 Linux에서 직접 실행할 수 없음 | 파일 내용은 유지하고 Git 실행 모드를 `100755`로 변경 |
| T03 학점 제한 | 두 요청이 모두 실패해도 기존 기대 조건을 만족할 수 있음 | 다른 실패 조건을 제외하고 정확히 한 요청 성공, 신청 행 1개 추가, 최종 18학점 확인 |
| T07 동일 과목 중복 | 두 요청이 모두 실패하는 경우를 배제하지 못함 | 순차·동시 사례를 분리하고, 각각 정확히 한 요청 성공 및 해당 과목 신청 행 1개 확인 |
| T08 시간 충돌 | 충돌 신청이 함께 저장되지 않는 것만으로는 정상 요청의 성공을 확인할 수 없음 | 각 강좌는 단독 신청 가능하도록 준비하고 정확히 한 요청 성공 및 최종 시간표 확인 |

변경된 검증 조건은 [요구사항](../REQUIREMENTS.md)의 T03·T07·T08에 반영했다. [후속 작업 요청](../../prompts/0003-review-follow-up.md)을 함께 기록한다.

## 검증 범위

- `git ls-files --stage gradlew`로 실행 모드 `100755` 확인
- 변경 전후 `gradlew`의 Git blob ID가 동일함을 확인하여 스크립트 내용 보존 검증
- 후속 변경의 `git diff --check`, `git diff --cached --check` 및 문서 내부 링크 점검
- 실행 로직을 바꾸지 않아 Java 빌드는 재실행하지 않음
- Linux에서 실제 실행하는 검증과 T03·T07·T08 동시성 테스트는 미실시. 이번 변경은 실행 권한 수정과 테스트 계획 보완임

사람 리뷰 및 머지는 후속 단계로 남긴다.
