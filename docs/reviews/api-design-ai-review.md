# API·상세 설계 AI 자체 리뷰

검토일: 2026-09-17. 문서 작성에 참여한 AI의 자체 검토이며 사람 리뷰와 구분한다. 범위는 7개 API 명세, 요구사항·데이터 모델·동시성·기술 선택, PR 계획과 관련 문답이다. 실행 기반 코드는 이번 리뷰 범위에서 제외했다.

## 반영한 의견

| 지적 | 근거·영향 | 처리 |
|---|---|---|
| 이미 확정된 물리 타입·학점·DTO 방침을 일부 명세에서 미정으로 표현 | D76~D78과 충돌하여 구현 기준이 달라질 수 있음 | 목록·신청·취소 명세 및 기술 문서를 갱신. API 숫자 상한 등 실제 미정 항목은 유지 |
| 잠금 방침을 기술 스택 선정 이후로 미루는 과거 문구 | D74~D75에서 스택과 JPA 우선 검증 방침은 확정됨 | 확정 방침을 참조하고 실제 SQL·설정 검증만 구현 단계로 구분 |
| 요구사항의 문서 작성 상태와 신청 PK 설명이 과거 상태 | 작성된 7개 명세 및 D76과 불일치 | 현재 명세 범위와 증가 BIGINT PK 반영 |
| PR 계획의 오탈자와 인증 선행 조건에서 강좌 조회 누락 | D50과 변경 계획의 불일치 | 학기·강좌·학생·학점 등의 오탈자 및 강좌 인증 조건 수정 |

## 게시 전 남은 사항

1. **설계·환경 PR 분리 반영:** 별도 설계 브랜치에서 서버 코드·Gradle·Compose·BOOTSTRAP.md를 제외했다. README와 기술 스택 문서의 실행 결과 및 해당 파일 링크도 분리했다.
2. **구현 전 계약 보완:** 공통 401 본문, 목록의 인증·입력 오류 우선순위, ID 입력 상한, JWT 키·재발급, 모의 계정의 테스트용 전달 방식 등은 여전히 미정이다. 설계 PR에 미정으로 남길 수 있지만 해당 기능 구현 완료 전에 확정해야 한다.

## 검증 범위

문서의 인증 범위, 신청·취소 대상 학기, 신청 조건·잠금 순서, 반복 취소, 시간표 정렬과 집계 정책을 요구사항과 대조했다. 문서 검사는 서버·DB·동시성·성능 테스트 결과가 아니다. 이 검토만으로 실제 구현의 정합성을 보장하지 않는다.
