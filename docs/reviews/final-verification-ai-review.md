# 신청·취소·시간표 AI 자체 검토

검토일: 2026-09-25. 기준 운영 코드는 119e384이다. 구현을 지원한 AI의 자체 검토이며 독립 리뷰나 사람의 승인으로 표시하지 않는다.

## 검토 범위와 결과

신청·취소의 트랜잭션 및 잠금 순서, 예외 응답 변환, 시간표 조회의 일관성, 실행 JAR 검증 스크립트를 검토했다. 검토 범위에서 확정된 기능 계약을 위반하는 결함은 발견하지 못했다. 보안 감사나 모든 실행 경로에 대한 무결함 보장은 아니다.

- 신청은 학생 잠금 이후 학생 조건을 새로 조회하고 통과한 요청만 강좌를 잠근다. 정원 COUNT는 강좌 잠금 이후 별도 쿼리로 실행한다. READ COMMITTED에서 선행 트랜잭션의 커밋을 반영하는 순서다.
- 취소도 학생 → 강좌 순서를 유지하고 본인·대상 강좌 조건으로만 신청 행을 삭제한다. 반복 취소 204 정책과 일치한다.
- 시간표는 같은 최초 조회 목록으로 본문과 학점을 계산한다. 수업 시간·교수는 후속 일괄 조회한다. 강좌 메타데이터의 신청 중 변경을 지원하지 않는 현재 정책을 전제로 한다.
- 잠금 일시 실패는 지정 SQLState에 한정해 503으로 변환한다. 모든 DB 오류를 재시도 가능한 실패로 숨기지 않는다. 자동 재시도는 구현하지 않는다.
- 기존 전체 실행의 587개 테스트 통과와 실제 JAR의 API smoke 결과를 확인했다. 이번 검토만을 이유로 동일한 전체 테스트를 다시 실행한 것은 아니다.

## 측정에 반영한 의견

빠른 409가 다수 발생하면 전체 평균·백분위가 성공 신청의 지연을 가릴 수 있다. 부하 스크립트에서 API와 결과 종류를 나누어 집계한다. 또한 3초 잠금 대기는 HTTP 전체 제한 시간이 아니므로 이를 응답 시간 보장으로 기록하지 않는다.

정확한 잠금 대기·연결 풀 압력 계측은 첫 HTTP 기준값 이후 필요성을 판단한다. 현재 결과만으로 잠금 방식 교체나 풀 확대를 결정하지 않는다. 사람 리뷰는 별도 진행 대상이다.
