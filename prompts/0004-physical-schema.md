# 물리 스키마 결정 정리

## 1. 계정 정보와 코드 형식

> 계정 정보는 현재 학생 테이블에 합쳐서 진행하고 추후에 분리를 고려하겠습니다. 과목 코드와 강좌 코드는 숫자로만 가능하게 하고, 나머지 컬럼 타입·길이, ID 생성 방식, 과목 정보와 초기 인덱스는 제안한 기본안으로 진행하겠습니다.

## 2. 학과명 유일성

> 학과명도 유일하게 하겠습니다. 서버에서는 PK로 구별할 수 있지만, 사용자 입장에서도 학과명이 유일하다고 생각할 것 같습니다. 중복된 학과는 없습니다.

## 3. 수업 시간의 종료 시각

> 제안한 대로 종료 시각이 24:00 미만이어야 한다는 제약을 추가하겠습니다.
